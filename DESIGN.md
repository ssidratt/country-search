
# Country Search. Design

## 1. Архитектура приложения

Приложение написано на TypeScript.

Основные модули:

* `src/main.ts`: интерфейс, обработка событий и управление поиском.
* `src/debounce.ts`: задержка вызова функции.
* `src/searchCountries.ts`: запросы к API и обработка HTTP ответов.
* `src/mapCountryResponse.ts`: преобразование данных API.
* `src/effects.ts`: звуковые эффекты.
* `src/globe.ts`: трёхмерная модель Земли.

Для разработки и сборки используется Vite.
Для тестирования используется Vitest.

## 2. Debounce

В `src/debounce.ts` реализована функция `debounce`.

Она откладывает вызов поиска до момента, когда пользователь перестанет вводить текст.

Задержка составляет 350 миллисекунд.

Это уменьшает количество сетевых запросов при быстром вводе.

## 3. Отмена запросов

В `src/main.ts` используется `AbortController`.

При изменении текста активный запрос отменяется.

В `src/searchCountries.ts` используется ограничение времени ожидания ответа.

Отмена пользователем и превышение времени ожидания обрабатываются отдельно.

## 4. Защита от устаревших результатов

В `src/main.ts` используется переменная `requestVersion`.

Каждый новый запрос получает свой номер.

Перед отображением результата проверяется, соответствует ли номер запроса актуальному.

Это предотвращает отображение устаревших результатов, даже если старый ответ пришёл позже нового.

## 5. Обработка ошибок

Приложение различает следующие ситуации:

* HTTP 404: страны не найдены.
* AbortError: запрос отменён пользователем.
* TimeoutError: превышено время ожидания.
* HttpError: сервер вернул другую HTTP ошибку.
* Сетевая ошибка: запрос не удалось выполнить.

При ошибке пользователь может повторить поиск кнопкой «Повторить».

## 6. Преобразование данных

Функция `mapCountryResponse` преобразует данные API в структуру `Country`.

Она не изменяет исходный объект.

Для массивов языков и валют используется метод `map`.

Если количество языков равно L, а валют C, временная сложность преобразования одной страны составляет O(L + C).

Для N стран общая сложность составляет O(сумма L + сумма C + N).

## 7. Принципы чистого кода

### Single Responsibility Principle

Каждый модуль отвечает за отдельную задачу.

Например, `searchCountries.ts` выполняет запросы, а `mapCountryResponse.ts` преобразует данные.

### DRY

Повторяющаяся логика поиска и отображения вынесена в отдельные функции.

### Разделение ответственности

Сетевые запросы не зависят от DOM.

Это позволяет тестировать их отдельно от интерфейса.

### Читаемость

Используются понятные имена функций, строгая типизация TypeScript и небольшие функции.

## 8. Тестирование

Тесты написаны с использованием Vitest.

Проверяются:

* Работа debounce.
* Формирование URL запроса.
* Передача AbortSignal.
* Обработка HTTP 404.
* Обработка HTTP 500.
* Ошибки AbortError и TimeoutError.
* Автоматический таймаут.
* Преобразование данных стран.
* Отмена предыдущего запроса при запуске следующего.

Для сетевых тестов используется имитация fetch.

Тесты не обращаются к реальному API.

## 9. Интерфейс

Интерфейс создаётся средствами DOM API.

Для динамического содержимого используются createElement, textContent и append.

Приложение поддерживает:

* Поиск стран.
* Сортировку результатов.
* Подробную информацию.
* Светлую и тёмную темы.
* Неоновые эффекты и анимации.
* Отключаемые звуковые эффекты.
* Вращающийся глобус на Three.js.

При системной настройке уменьшения движения анимация глобуса останавливается.
